# Deploy and Connect

## Local Development

1. Run MCP server locally.
2. Tunnel HTTPS with ngrok or similar.
3. Refresh connector after changes.

## Connect in ChatGPT

1. Enable developer mode.
2. Create connector in Settings -> Connectors.
3. Provide HTTPS `/mcp` URL.
4. Add connector to a conversation via the plus menu.

## Testing

- Use MCP Inspector for tool and UI checks.
- Run golden prompts in developer mode.
- Test on mobile layouts.

## Submission

- Must host on a public domain with CSP configured.
- Review guidelines, then submit via OpenAI dashboard.
- Tool names and schemas are locked after publish.
