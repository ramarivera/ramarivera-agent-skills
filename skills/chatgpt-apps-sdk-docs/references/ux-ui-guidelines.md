# UX and UI Guidelines

## UX Principles

- Use conversational leverage, native fit, and composability.
- Extract core jobs, do not port full apps.
- Optimize for conversation, not navigation.

## Display Modes

- Inline cards for quick actions or summaries.
- Carousels for small sets of visual items.
- Fullscreen for rich workflows.
- PiP for ongoing sessions like games or media.

## Visual Guidelines

- Use system font stack; avoid custom fonts.
- Use system colors; keep brand accents subtle.
- Avoid nested scrolling and deep navigation in cards.
- Provide alt text and meet WCAG AA contrast.
