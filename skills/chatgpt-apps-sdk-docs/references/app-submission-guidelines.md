# App Submission Guidelines (Highlights)

## Tool Quality

- Use clear, accurate tool names and descriptions.
- Set correct annotations for read-only, open-world, and destructive tools.
- Request minimal input fields tied to the task.

## Policy and Safety

- Do not use ads or misleading content.
- Respect privacy and data minimization.
- Avoid prohibited goods and services.

## Commerce Limits

- Physical goods only are allowed today.
- Digital goods and subscriptions are not allowed.

## Auth

- Provide working test credentials for review if required.
- Avoid flows that require inaccessible 2FA.
