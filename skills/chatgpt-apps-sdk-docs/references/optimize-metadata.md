# Optimize Metadata

## Golden Prompts

- Build direct, indirect, and negative prompt sets.
- Track expected tool selection for each prompt.

## Tool Metadata

- Use action-oriented names and clear descriptions.
- Start descriptions with "Use this when...".
- Use readOnlyHint, openWorldHint, destructiveHint appropriately.

## Iteration

- Change one field at a time.
- Retest in developer mode after each change.
- Keep a changelog of metadata revisions.
