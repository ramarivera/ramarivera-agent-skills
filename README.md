# Ramiro's Agent Skills

This repository is my personal home for agent skills and related resources.

## Purpose

- Store and organize reusable skills for coding agents
- Keep drafts, experiments, and polished skills in one place
- Track updates over time with git

## Structure

- `skills/` for individual skills (each in its own folder with a `SKILL.md`)
- Optional helper assets like scripts, references, and docs

## Notes

This is a working repo for "skills and whatever" that supports ongoing iteration.
